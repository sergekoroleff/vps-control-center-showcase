# VPS Control Center — Public Showcase

**[Посмотреть сайт →](https://sergekoroleff.github.io/vps-control-center-showcase/)**

Публичная презентация персонального Telegram-бота для мониторинга собственной VPS-инфраструктуры и управления VPN-клиентами.

## Возможности

- Единый обзор VPS, статусов и сводной активности.
- VPS Performance и Service Reliability за 24 часа.
- Наблюдение за AmneziaWG 2.0 и 3.1, Telegram MTProto Proxy и AML & KYC Scanner.
- Управление профилями AWG 3.1: создание, переименование, выдача подключения и отзыв доступа.
- Выдача конфигурации и QR по запросу в личном Telegram-чате с очисткой сообщений.
- Daily Infrastructure Report: таймер ежедневной сводки настроен на 21:00 МСК; первая полноценная статистика требует накопления истории.

## Архитектура

Telegram Bot (без root и Docker socket) → очищенные снимки мониторинга / ограниченная очередь заявок → отдельные системные обработчики → VPN и инфраструктурные сервисы.

## Реальные скриншоты

Шесть пользовательских скриншотов находятся в `assets/screens/` и демонстрируются в адаптивной галерее с просмотром изображений. Для публичного сайта изображения оптимизированы, служебные сведения не используются в коде и логике интерфейса.

## Защита данных

Публичный репозиторий не содержит IP-адресов, токенов, конфигураций, приватных ключей и кода привилегированного обработчика. Пересылка VPN-конфигураций через Telegram не является сквозно зашифрованной; эта особенность явно описана на сайте.

## Telegram Mini App · v0.5 LIVE (18.10.2026)

В Telegram через меню BotFather запущена **настоящая read-only Mini App**. Четыре экрана подтверждены реальными данными и скриншотами:

- **Обзор** — актуальные статусы процессов, RAM/диск, агрегированная активность VPN и история.
- **Сервер** — показатели VPS, load average, история RAM за 24 часа и сетевые метрики.
- **VPN** — AWG 2.0/3.1, окно handshake 3/15/60 минут, накопленные RX/TX и список собственных профилей в защищённой панели.
- **События** — наблюдаемая надёжность четырёх сервисов и внешний watchdog Cronitor.

**Архитектура для публичного описания:** React/TypeScript/Vite frontend + отдельный read-only Python API + HTTPS через outbound ngrok + подписанные Telegram WebApp initData и allowlist. Не публиковать закрытый адрес Mini App, имена клиентов, пароли, IP или другие секреты.

На странице появился раздел [Mini App](https://sergekoroleff.github.io/vps-control-center-showcase/#miniapp), оформленный в прежнем Mission Control стиле. Для него предусмотрены четыре обезличенных снимка по путям `assets/screens/07-miniapp-overview.webp` … `10-miniapp-events.webp`. До размещения файлов сайт отображает аккуратные заполнители вместо битых изображений.
