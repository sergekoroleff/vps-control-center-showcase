# VPS Control Center — Showcase

Публичный презентационный сайт персонального Telegram-бота для мониторинга собственной VPS-инфраструктуры и управления VPN-клиентами.

**Сайт:** https://sergekoroleff.github.io/vps-control-center-showcase/

## Функциональность

- Обзор инфраструктуры, VPS Performance за 24 ч.
- Мониторинг AmneziaWG 2.0, AmneziaWG 3.1, Telegram MTProto Proxy и AML & KYC Scanner.
- История наблюдений Service Reliability за 24 часа.
- Создание, переименование и отзыв VPN-профилей AWG 3.1 с подтверждением.
- Получение VPN-конфигураций и QR-кодов в личном чате, с удалением сообщений после использования.
- Daily Infrastructure Report: плановая отправка в 21:00 по Москве. Запуск и полнота первых отчётов зависят от накопления истории.

## Архитектура и безопасность

Telegram-бот запускается без root и без Docker socket. Мониторинг осуществляется через очищенные от чувствительных данных снимки, а операции над VPN — через отдельную очередь и привилегированный обработчик с ограниченной логикой.

> QR-коды и `.conf` содержат приватные ключи, а Telegram-боты не используют сквозное шифрование. Публичный репозиторий не содержит VPN-конфигураций, IP, приватных ключей и подробностей доступа.

## Галерея

Шесть иллюстраций в `assets/screens/` предоставлены владельцем проекта. Для публичной версии изображения оптимизированы; отдельные идентифицирующие и эксплуатационные данные могут быть скрыты.

## Технологии showcase

Нативный HTML5 + CSS3 + JavaScript, без сборщика, CDN, фреймворков и сторонней аналитики. Работает на GitHub Pages как статический сайт; галерея поддерживает просмотр, клавиатуру и мобильную вёрстку.

## Публикация GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.

Этот **публичный репозиторий содержит только демонстрационный сайт**, не исходники привилегированного обработчика и не инфраструктурные конфигурации.
