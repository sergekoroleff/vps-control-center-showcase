05 / SECURITY MODEL

Контроль без
лишних привилегий.

Архитектурные решения, которые важнее красивой кнопки управления.

01

Private access

Доступ к управлению ограничен списком Telegram ID и личным чатом администратора.

02

Privilege separation

Бот не выполняется под root и не имеет прямого доступа к Docker socket.

03

Explicit confirmation

Создание и удаление VPN-профилей требуют подтверждения. Важные операции обрабатывает отдельная служба.

04

Secret-aware delivery

QR-код и .conf передаются по запросу с последующей очисткой сообщений. Бот-чаты Telegram не имеют E2E-шифрования.

✳

Принцип проекта: безопасный мониторинг по умолчанию, минимально необходимые права для изменений, без публикации приватных VPN-ключей и конфигураций.
