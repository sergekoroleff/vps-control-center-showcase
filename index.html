Crypto first

Браузерный Web Crypto, выбор без статистического смещения (rejection sampling), никаких Math.random или слабого запасного генератора.

02

Private by design

Секрет не уходит в API и не хранится в логах или аналитике. Исходный словарь EFF загружается как публичный статический ресурс с проверкой SHA256.

03

Animation with discipline

Хаотичные декоративные буквы постепенно превращаются в слова. Настоящий секрет создаётся только в конце эффекта; смена вкладки отменяет генерацию и очищает результат.

04

Release engineering

Релиз из проверенного коммита GitHub, автоматические тесты, безопасная установка с backup/rollback, тест владельца и итоговый SHA256-контроль 6/6.
